# SUPER U 叠箱排柜工作台 v2.0.1 beta

独立测试入口：`/v2/`。原版页面、算法和数据存储键均保留不变。

## 快速测试

1. 打开 `v2/index.html` 对应的 HTTP / GitHub Pages 地址。
2. 首次打开会载入 **22 箱演示货物**，包含一个“一托二”组合。
3. 进入 **叠箱工作台**，点击箱子，在俯视或侧视图拖动，或输入 X / Y / Z 坐标。
4. 用“参考箱”和“放到上方 / 沿 X 并排 / 沿 Y 并排 / 底面居中”调整。可撤销。
5. 保存组合；点“复制此组合”，复制 5 份。库存会从真实剩余箱号中分配。
6. 进入 **集装箱排柜**，选择柜型并计算。组合整组保留，散箱一起排柜。
7. 到 **装柜指引** 导出 Excel 或打印为 PDF。下载项目 JSON 后可在另一台电脑恢复。

## 本版实现

- 唯一箱号、组合内部坐标、允许方向、真实库存占用，复制和解散组合。
- 一托二、二托一、并排、叠放；平面拖动、边缘吸附、键盘微调、数值定位和撤销。
- 同底面自动组箱；组合只允许整体平移和允许的水平旋转。
- 多工作表 Excel / CSV 导入预览、尺寸单位换算、缺尺寸行保留、箱数异常阻止导入。
- 共用的几何与规则验证：碰撞、悬空、支撑率、双方向外挑、已知重量关系、累计上压重量、向上传递的层数限制。
- 常规高度默认 2570 mm，并受实际柜内高度约束。柜门净尺寸可另行填写。
- 多种已安排柜型、额外加柜开关、20GP / 40GP / 40HQ / 45HQ 的同规则比较。
- 只有末柜 1–2 个已知轻箱可省整柜时，单独提出超常规高度的柜内补顶候选，需明确采用。
- Web Worker 计算、取消、过期任务隔离、结果指纹和数量/组合审计。
- 本地草稿恢复、完整项目 JSON、Excel 明细、SVG 示意和中文浏览器打印 PDF。
- 不依赖 WebGL 的俯视、侧视与立体示意；可用时支持 Three.js 旋转预览。

## 明确边界

- 组合先以外包尺寸占位，整组安排在柜底，内部空隙暂不自动塞箱。可在真实有效顶面上继续放散箱。
- 原型不包含排柜结果中的手工挪组/位置锁定，也不做自动拆组；调整应返回叠箱工作台后重算。
- 柜型比较按未装入数、柜数、总柜内容积排序，未纳入运价；没有宣称全局最优。已安排柜型不自动降级。
- 外挑默认为 0，支撑率默认为 100%。外挑阈值指同一方向两端外挑量的总和，不能长宽双向同时外挑。支撑中心检查是保守几何检查。
- 重量未知不当作已验证的零重量。承压缺失会警告；上压为 0 kg 表示不能承受上压重量。
- 图中顺序是建议顺序，不是实际进门、叉车/人工搬运路径仿真，也不证明运输安全。补顶与箱体承压、加固需生产核实。
- 项目最多 3000 箱、最多 30 个已安排柜；复杂项目可取消或分批测试。
- 项目在当前浏览器保存，不上传业务数据；浏览器清理存储前请下载 JSON。

## 开发与验证

无构建步骤；复用原仓库已固定的 Three.js / SheetJS 库。

```sh
python -m http.server 8765
node --test v2/tests/core.test.cjs
```

`core.js` 是浏览器 / Worker / Node 共用的纯计算模块。回归覆盖组合、方向、支撑、重量、层数、混合柜、已安排柜数、库存守恒、补顶和导入边界。
