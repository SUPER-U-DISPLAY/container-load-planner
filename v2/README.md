# SUPER U 叠箱测试版 v2.2

独立测试入口 `/v2/`；原生产入口 `/` 的文件不变。

## 本版范围

- `/v2/index.html` 恢复原版页面。结果区 HTML、统计/明细渲染代码，以及原版 3D 查看器、播放、图片、PDF、Excel 导出继续复用。
- 顶栏增加“叠箱组合”，打开独立的 `/v2/stack.html`。导入装箱单仍在原来的顶部入口。
- 包装模型按装箱单长、宽、高生成；不是产品外观模型。左侧每种包装一个模型，工作台按真实尺寸显示；右侧保存组合立体预览。
- 左键从模型区拖箱到工作台，或拖工作台已有箱子；右键转视角，滚轮缩放，Shift + 右键平移。支持顶面/边缘吸附、合法/非法提示、撤销、允许方向旋转、数值定位。
- 每只实箱有唯一箱号；复制组合占用新的数量，解散归还数量。固定组合参与排柜时保持内部位置和方向。
- 同时检查碰撞、支撑面积、外挑、中心支撑、重箱在下、累计上压重量、最大叠层和常规高度。禁止承叠/零承压的箱子仍可用作顶箱。
- WebGL 可用时直接使用 Three.js；没有 WebGL 时同一 3D 场景、相机、光线拾取与拖动使用 Canvas 兼容渲染。

## 试用

1. 在 `/v2/` 顶栏导入 Excel / CSV 装箱单。
2. 点“叠箱组合”；没有数据也可在叠箱页点“试用叠箱示例”。
3. 拖入一只底箱，再将上箱拖到其顶面。绿色可松手，红色提示原因并拒绝放置。
4. 点“保存组合”，右侧可查看、编辑、复制或解散。
5. “返回排柜”沿用原版的三维结果、播放、统计和导出。未保存草稿需先保存或放弃。
6. 叠箱页“项目 / 规则”可导出/打开项目备份，调整共同叠放规则；选中箱子后可设置该箱型的上压承重及层数。

## 实现

- `core.js`：无 DOM 的统一规则与排柜引擎，真实库存及组合完整性审计。
- `bridge.js`：共享本地项目，将新排柜结果逐箱转换为原版结果数据格式。
- `legacy-ui.js`：原版 UI 的薄适配，结果渲染部分保持原样。
- `scene3d.js`、`scene-math.js`：3D 相机、拾取、拖动、吸附和共享规则校验。
- `stack-app.js`：模型库存、草稿与组合操作。
- `renderer.js`：WebGL 失败时的 Canvas 兼容渲染。
- 旧 v2.0/v2.1 文件保留作历史参考，新入口不再使用旧页面控制器。

## 边界

组合以外包尺寸占位并放在柜底，暂不把散箱填入组合包围盒的内部空隙。已分组箱子的相对摆放不会被排柜算法拆散；散箱可在验证通过的有效顶面继续叠放。

常规高度默认 2570 mm，支撑率默认 100%，外挑默认 0；可在“项目 / 规则”调整。未知重量或承压值会提示待确认，不能据此视为承重已验证。显示的是几何排柜及建议装柜顺序，不包含搬运路径或运输动力学仿真。

单项目最多 3000 箱、最多 60 个配置柜。计算沿用原版主线程流程；复杂大单可分批。项目保存在本机浏览器；换设备或清理浏览器前请导出 JSON 备份。
