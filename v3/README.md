# SUPER U 学习版 v3.0.0

独立测试入口 `/v3/`。原 `/`、`/v2/` 保持原版本，原结果区的外观、统计、播放与导出继续复用。

## 试用流程

1. 顶栏导入装箱单 → “叠箱组合”。支持一键生成、手动拖动、三轴 90° 翻转、位置输入及保存组合。
2. “去排柜” → “开始排柜” → “调整柜内摆放”。在独立页面移动、换柜、旋转或暂存，支持锁定和重排未锁定部分。
3. “保存调整并去排柜” → “确认最终方案”。日常调整不用选理由，最终确认的理由也可不填。
4. “历史与学习”保留每次确认、查看差异、载入为新方案、补充实装和到货反馈。
5. 新箱单会尝试复用匹配的历史组合；负责人可分析历史、查看候选效果、发布或切换已发布经验版本。

## 本版学习

- 精确匹配包装条件的组合模板，以及可映射、仍通过现行检查的历史整柜布局。
- 同输入约束下的人工最终结果，与系统原始推荐形成偏好对。输入变化切断旧对，练习、重复、原样采纳和货损记录不用于偏好训练。
- 按独立项目族划分训练与留出验证，样本不足先积累模板。偏好排序只影响新计算，不会改写历史确认布局。
- 不通过学习放宽支撑、承压、禁压、朝向、柜门、载重或组合独占柜底等规则。未知承压继续提醒生产确认。

## 本机与共享

GitHub Pages 可直接测试本机学习，数据存于当前浏览器的 IndexedDB。多人共享需部署仓库 `server/` 服务并接入 ERP 身份验证，提供项目权限、修订冲突检查、确认版本、后台计算任务、照片与经验发布。

完整说明、配置、ERP 接口契约与备份方法见 [部署文档](../docs/LEARNING_DEPLOYMENT.md)。尚未连接 ERP 时，页面明确显示“本机试用”。

## 验证

Node.js 24：`npm ci`、`npm test`。无需前端构建，Three.js、Excel、PDF 库复用仓库已固定的本地文件。

核心模块：`core.js` 统一规则；`layout.js` 人工摆放校验；`experience.js` 案例、模板与偏好；`learning-client.js` IndexedDB、同步及服务适配；`history.html` 历史与学习管理；`edit.html` 独立柜内编辑。

当前是几何排柜、案例复用与偏好排序，不含运输动力学仿真。确认方案、按此实装和到货完好是三种独立证据。
