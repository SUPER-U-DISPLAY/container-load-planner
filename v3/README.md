# SUPER U 学习版 v3.3.0

独立测试入口 `/v3/`。原 `/`、`/v2/` 保持原版本，原结果区的外观、统计、播放与导出继续复用。

## 试用流程

1. 顶栏导入装箱单 → “叠箱组合”。支持一键生成、手动拖动、三轴 90° 翻转、位置输入及保存组合。
2. “去排柜” → “开始排柜” → “调整柜内摆放”。在独立页面移动、换柜、旋转或暂存，支持锁定和重排未锁定部分。
3. “保存调整并去排柜” → “确认最终方案”。日常调整不用选理由，最终确认的理由也可不填。
4. “历史与学习”保留每次确认、查看差异、载入为新方案、补充实装和到货反馈。
5. 新箱单会尝试复用匹配的历史组合；负责人可分析历史、查看候选效果、发布或切换已发布经验版本。

## 本版学习

- 精确匹配包装条件的组合模板，以及可映射、仍通过现行检查的历史整柜布局。
- 同输入约束下的人工最终结果，与系统原始推荐形成偏好对。输入变化切断旧对，练习、重复、原样采纳和货损记录不用于偏好训练。
- 按独立项目族划分训练与留出验证，样本不足先积累模板。偏好排序只影响新计算，不会改写历史确认布局。
- 不通过学习放宽支撑、承压、禁压、朝向、柜门、载重或组合独占柜底等规则。未知承压继续提醒生产确认。

## 本机与共享

GitHub Pages 可直接测试本机学习，数据存于当前浏览器的 IndexedDB。多人共享需部署仓库 `server/` 服务并接入 ERP 身份验证，提供项目权限、修订冲突检查、确认版本、后台计算任务、照片与经验发布。

完整说明、配置、ERP 接口契约与备份方法见 [部署文档](../docs/LEARNING_DEPLOYMENT.md)。尚未连接 ERP 时，页面明确显示“本机试用”。

## v3.3 联合预排与利用率优化

- 默认改为“联合预排”：保留几何、支撑、承压、禁压、朝向和已保存组合独占柜底等硬规则；防倒需求作为明确的待核实施工条件，单独生成方向、位置、拟用侧挡/直接固定、受力路径和初筛需求力。不是撤销检查，也不是已通过运输验收。需要严格自稳筛选时，可在“项目与叠箱规则 → 预排与加固”切换。
- 在目标柜数内比较高度、体积、底面、临时上下组合、二托一和多种确定性顺序，再尝试跨柜回填。临时搜索组合不成为用户保存的刚性组合，最终库存审计仍逐箱执行。最多180个搜索物品启用额外排序；较大项目使用基础候选。有限搜索失败只表示未找到，不是无法装入的数学证明。
- 默认叠高仍为2570mm，单件超高不自动豁免。生产可显式开启“单件超过叠高时落地预排”，单独核实真实柜门净尺寸、进柜余量、包装公差和搬运方式。已知柜门或柜内边界冲突仍拒绝；不能把超高整件叠到上层。
- 同一批候选的同币种柜费及加固点组费用全部齐全时统一比较估算总费用；存在缺价时整批统一按柜数/空间排序，避免逐对切换依据导致排序不一致，缺价不补0。柜型推荐在后台线程比较常用柜型及高柜末柜改小柜的混配，保留未装入数，采用后仍按完整箱单重算。非常用柜型只有已在项目配置中时才纳入推荐。
- 箱型规则支持重量来源与包装模板。模板按明确尺寸、重量上限及生产依据复用，携带规则版本；不会按产品名推断承压，也不会把模板来源的“实称”标记复制成其他箱子的重量来源。
- 已保存组合保持整组落地、上方不再加货。手动调整、共享服务器、存档重放和导出使用相同校核；篡改结果里的“已通过”字段无效。加固、承压、估重、进柜或缺尺寸未处理的方案不能进入正式经验学习。
- 结果页排版、模型、播放与导出操作保持；状态明确为“条件预排”，图片和PDF标题带待核实标记。原规则提示可查看并导出全部加固、承压、进柜及未装入条件CSV。

### 加固方案的适用边界

加固清单是待核实的规划数据，不是施工图。箱体重心仍按几何中心估算，两轴0.8g/竖直1g只作保守初筛。需求力不计摩擦信用，不可直接换算成绑带条数或撑木截面。相邻货物和柜壁均不自动视为具有额定承力；路径按单调方向追踪，不允许循环依赖作为安全证明。300mm仅用于选择示意方法，不是规范限值。材料用量中的40×40mm是示意截面，不是强度选型；占用空间、材料规格、固定点、包装侧压和临时支撑工序仍需现场核定并复核布局。货物利用率只计原箱单货物，不计示意加固材料。

## v3.2 无约束高叠硬限制（仅自稳模式继续保留）

- 修正 v3.1 只提示但仍保留危险高叠的问题。倾倒初筛发现上箱或其承载链不稳时，直接拒绝候选放入、手动上叠和历史回放（统一使用 `validatePlacement`；底层 `validate` 仍仅作几何/承压检查）；算法先落地、降层或选择已允许的姿态，放不下则列入未装入清单。
- 约束在正式排柜、叠箱建议与保存、手动柜内编辑、服务端复核和最终库存审计中一致执行。关闭候选优化不会关闭硬限制；虚拟组合、贴墙、相邻箱接触以及伪造通过标记都不能豁免。
- 未确认重量的承载链暂不自动上叠；稳定的低叠仍允许。现版没有额定侧向加固模型，因此不能由系统自行认定某种绑扎或邻货足以允许高叠。
- 此项硬限制针对叠放。落地窄高件仍需按提示进行独立固定，落地不等于已完成运输加固。
- 结果中的“重心居中”仅指整柜重量分布，不代表某件货物防倒。旧版计算缓存升级失效，需要重新计算；不自动拆开用户保存的组合。

## v3.1 防倾倒与防误叠

- 自动比较基础、降低倾倒暴露、紧凑摆放和窄高件先定位的候选；整柜排完后尝试移动完整支撑链以减少暴露，移动不拆组合、不破坏支撑，也不恶化已有的重心偏移。没有找到更好位置时保留明确的加固要求。
- 允许的侧放、平放才参与自动选择；固定朝向和单箱手动翻转例外保持原规则。保存组合仍独占柜底，顶部不加外部货物。
- 前后与左右分别检查，并将上箱荷重计入各层承载链的估算重心。相邻低箱、易碎箱、存在缝隙或自身窄高的箱子不自动当作可靠侧挡；贴柜壁也不视为加固完成。
- 在“项目与叠箱规则”中确认包装类型、允许朝向和上压值。名称/备注含玻璃、镜子、镜柜、大理石等的货物先按易碎品防误叠；易碎货即使装木箱，仍须有明确上压值才能承托上箱。普通货物可显式纠正识别结果。
- 规则、柜内编辑、计算服务、历史方案复用使用同一套校验。手动移动、旋转、删除或换柜后，重新计算整柜的防倒提示；旧版缓存因引擎指纹升级而重新计算。待加固布局可保存，但不进入模板与偏好学习。
- 原结果页的中栏/右栏 HTML、模型、动画、明细与导出操作不重排；仅更新原有提示文案、详情备注、重心提示阈值和规则编辑内容。Excel 明细的备注保留防倒要求。

### 初筛边界

当前使用箱体几何中心、已知重量（缺重量时用几何假设）和承载链作初筛，采用两轴水平 0.8g、竖直 1g 的保守试用假设。这不是针对实际海域、运输方式、摩擦系数及包装结构计算的 CTU 加固验算，也没有输入绑扎点/绑带/支架/箱壁的实际承力。相邻接触只降低“缺少侧挡候选”的暴露评分，绝不使窄高件自动成为已加固货物。现场还需确认装卸期间的临时支撑、包装受力和最终固定方式。

重量为估算值或箱内实际重心未知时，重心结果同样只能用于初步判断。全部装入、几何检查通过、布局确认、按此实装和到货完好是不同证据。
